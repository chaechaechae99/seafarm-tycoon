# 요구사항

## 플랫폼
- PC 웹 브라우저(Chrome·Edge 최신), 설치 없이 `index.html` 실행 또는 URL 접속
- 정적 사이트: Cloudflare Pages · GitHub Pages 배포
- 이모지 없이 도트 아트·텍스트 UI

## 화면·조작
- 게임 월드 480×270(16:9) 고정, 정수배 확대
- 좌클릭 드래그·WASD 이동, 휠 줌(1~4배), 맵 경계 밖으로 카메라 이동 불가
- 홈 버튼·H 키로 기본 위치(1배) 복귀
- 오른쪽 접이식 사이드바, 비밀 양식장·VIP·수족관 빠른 열기

## 게임 내용
- 가두리 낚시터: 실존 양식·연안 120종(일반·고급·희귀·명품·전설, 난이도 1~5), 손님 4유형, 시설 8종, 업그레이드 16종, 계절·날씨·밤낮
- 원정: 350종 데이터, 구역 6곳 해금, 원정 낚시꾼 고용 후 무료 파견(1분·15분·1시간·6시간·24시간, 1분당 1마리, 길수록 전설·심해 확률 상승) → 원정 전용 선착장에서 출항·귀항
- 사장님 낚시: 스페이스바 단타 + 자동 낚시 토글(30초 간격, 꽝 없음)
- 손님 동선: 매표소 또는 여객선 → 길 그래프 다익스트라 최단 경로로 걸어서 입장·퇴장
- VIP 호감도 Lv1~100, 비밀 양식장(7천만 원) VIP 전용 좌대 12석, 원정 어종·교배 신종만 출현
- 교배: 같은 어종 등급 상승(3단계), 같은 계열 대표종 22칸 + 이색 레시피 22칸 = 신종 도감 44칸, 실루엣·3단계 힌트
- 수족관: 희귀 이상 6마리 등록, 매출 버프, 육지 건물 창·탭 화면에서 헤엄
- 크기: 고래·대형 어종은 `size-overrides.json`의 실제 크기, 거대 신종 최소 15m
- 오프라인 보상 최대 8시간, localStorage 자동 저장, 저장 코드 내보내기·가져오기
