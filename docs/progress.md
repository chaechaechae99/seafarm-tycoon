# 진행 상황 (2026-10-21)

## 상태
플레이 가능한 완성 빌드. `npm test` 22개 통과, 헤드리스 브라우저로 낮·밤·태풍·확대·각 탭 화면과 CSP 적용 배포 빌드에서 오류 없음 확인.

## 숫자로 본 현재 게임
- 어종: 가두리 48종 + 원정 350종(크기 보정 52종), 신종 도감 44칸
- 맵: 640×360, 좌대 6개(36석 표시), 손님 동선 노드 그래프
- 밸런스(탐욕 봇): 초당 수익 10분 약 110원, 30분 약 1.7만원, 60분 약 18만원. 원정 구역은 31·42·51분에 해금
- 배포 빌드: 파일 16개, 약 540KB, 외부 요청 없음

## 최근 변경
- 원정 어선 파견 팝업: 가두리에는 연안 어종만, 고래·심해 생물은 파견(1·2·3분)으로 획득 → 교배 재료·수족관 등록에 바로 쓰임
- 자동 낚시 토글: 30초마다 자동으로 던지고 꽝 없이 성공
- GitHub Pages 배포 워크플로 추가
