# 진행 상황 (2026-10-21)

## 상태
플레이 가능한 완성 빌드, GitHub Pages 배포 중 (https://chaechaechae99.github.io/seafarm-tycoon/). `npm test` 22개 통과, 헤드리스 브라우저로 낮·밤·확대·각 탭·예전 저장 불러오기 확인.

## 숫자로 본 현재 게임
- 어종: 가두리 120종(실존 양식·연안, 5등급·난이도) + 원정 350종(크기 보정 52종), 신종 도감 44칸
- 맵: 640×360, 좌대 15개(3줄 × 5칸, 최대 150석 표시), 윗다리·아랫다리, 손님 동선 노드 그래프
- 손님: 페르소나 11종(고등학생·대학생·직장인·어르신·커플 등) 외형과 이름 타이틀
- VIP: 호감도 Lv1~100, 비밀 양식장(7천만 원) 12석, 원정 어종·교배 신종만 출현
- 원정 파견: 무료, 1분·15분·1시간·6시간·24시간, 원정 낚시꾼 고용 후 해금
- 밸런스(탐욕 봇): 초당 수익 30분 약 3만원, 60분 약 18.7만원

## 최근 변경
- 맵 640×360으로 확대(도트가 75% 크기로 촘촘해짐), 아랫다리와 셋째 줄 좌대 추가
- 예전 형식 원정 결과가 든 저장을 불러오면 화면이 멈추던 문제 수정, 프레임 오류가 게임 루프를 멈추지 않게 보호
- 원정 전용 선착장 분리, 원정선 레이어 수정
